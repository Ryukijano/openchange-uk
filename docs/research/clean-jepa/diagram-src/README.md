# Diagram sources

Sources for the diagrams in this folder, copied from the design workspace so the
committed artifacts stay editable.

- `repository-body.html` — the body fragment compiled into
  [../training-diagram.html](../training-diagram.html). Edit this, then recompile
  with the same standalone-artifact tooling; do not edit the compiled file.
- `body.html`, `pipeline_svg.html`, `build_svg.py`, `starter_diagram.html` —
  generator and fragment for the superseded [v1 diagram](../plans/training-diagram-v1.html).
- `shots/` — desktop and 375 px render checks of the current diagram.
