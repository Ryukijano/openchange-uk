Selected design, not a training result

Train one shared Sentinel-1/2 encoder with a live global-view centre and a per-view Gaussianity statistic. Test loss-based selection, version compatibility and missing-sensor utility against matched Barlow Twins and MAE. The repository contains the formulation and implementation work packages; the JEPA trainer is not implemented yet.

Missing-sensor decision

Keep the full N(0,I) target as a pilot candidate. Uniform stratum weights, global token drop 0.9, local drop 0.5 and drop-path 0 are our choices. Stop scaling this candidate if robustness comes at unacceptable clean-task cost or shared-factor loss. A reduced-covariance/shared-subspace target would require a separate protocol.

The exact loss convention

zn,v = g(f(xn,v)), μn = (zn,1 + zn,2)/2. There is no detach or predictor.

Linv = (1/NVK) Σn,v ‖zn,v − μn‖². This averages coordinates; a sum over K would change the regularization ratio by K.

For each view/stratum and unit direction aj, Cjl = meann cos(tlajTzn), Djl = meann sin(tlajTzn). Set φl = exp(−tl²/2).

EP = (Nm/M) Σj,l ql[(Cjl − φl)² + Djl²], where q already includes the Gaussian window and doubled trapezoid weights. M=1024; t=0,…,3 on 17 knots. Compute in fp32 with autocast disabled.

SIGRegstrat = meanv Σm (1/4) EPm,v. Tμ = meanv Σm (1/4) Nm‖z̄m,v‖²/K.

L = (1−λ)Linv + λ SIGRegstrat + λμTμ, λ=.05 initially, λμ=0 in the main arm. Counts and K remain fixed for comparable selection cohorts.

Do not confuse the null expectation with an optimum

Independent Gaussian samples give expected EP ≈1.0525 under this quadrature, not an irreducible loss floor. Full conditional Gaussianity may conflict with missing private information. Low empirical EP or a weak availability probe does not guarantee semantic alignment or useful sensor substitution.

Accounting and limits

Count post-drop patch tokens entering every encoder view, excluding CLS. Expected count ≈208 for a joint item and 148 for a single-sensor item; four equal strata average ≈178. Log actual counts. Repeated visits are not new unique data, and MAE decoder/projector/EP compute belongs in the ledger.

Earlier GPU-hour and 750/1100 NHR estimates were unverified FLOP scenarios. The benchmark's 5,000 NHR planning envelope already assigns the full budget; the award scope and remaining balance are not confirmed. Price the combined programme from measured I/O, memory, step time and efficiency before scale-up.

This is not a world-action model: there is no action-conditioned rollout or intervention evaluation. No dataset was fetched, no EO training was run and no cluster job was submitted for this documentation update.
