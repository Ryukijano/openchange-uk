Formulation

Notation: sample n = 1…N (global batch, fixed at 1024), view v = 1…V (V = 8: 2 global, 6 local), availability stratum mn ∈ {m1, m2, m3, m4}. Backbone f maps a token sequence to Rd; projector g maps Rd → RK, K = 128. Embedding zn,v = g(f(xn,v)).

Invariance (the only alignment term)

μn = ½ (zn,1 + zn,2) over the two global views, and

Linv = (1 / N V K) Σn,v,k (μn,k − zn,v,k)2.

Fact (official MINIMAL code): per-coordinate MSE, no normalisation, no stop-gradient on the centre. For an S1-only local view this pulls the S1 embedding onto the full-observation centre, which is what makes the strata overlap rather than merely each be Gaussian.

SIGReg (Epps–Pulley on random 1-D slices)

Draw M = 256 unit directions aj ∈ RK each step (same seed on every DDP rank). For a set S of embeddings and knots tl = linspace(0, 3, 17) with trapezoid weights ωl and Gaussian window φ(t) = e−t²/2:

Re ψj(t) = (1/|S|) Σn∈S cos(t ajTzn), Im ψj(t) = (1/|S|) Σn∈S sin(t ajTzn),

EP(S) = |S| · (1/M) Σj Σl ωl φ(tl) [ (Re ψj(tl) − φ(tl))2 + (Im ψj(tl))2 ].

Pooled SIGReg (the paper) = mean over views of EP({zn,v : all n}). Fact: the statistic is multiplied by the sample count, so the effective weight of SIGReg relative to Linv depends on N; hence the fixed global batch and the rule that loss totals are never compared across different N. Paper recommends 1024 slices on [−5, 5]; code uses 256 on [0, 3] (symmetric integrand, so [0,3] covers [−3,3]); the paper's Table 1a shows under 0.5 points between the two. We pre-register the code convention.

Availability-stratified SIGReg (method contribution M)

SIGRegstrat = meanv Σm wm EP({zn,v : mn = m}), wm = Nm / N; with four strata, Nm ≥ 256 and N = 1024 this forces Nm = 256. Default wm = 1/S regardless: the per-sample SIGReg gradient is O(1) in Nm, so Nm/N would multiply the push on each rare-stratum sample by its frequency, down-weighting exactly the strata the method targets (measured: rare stratum gets 2.4e-3 vs 9.8e-3 per-sample gradient under Nm/N vs 1/S).

At the optimum each stratum is N(0, IK) in projector space, so z is independent of m: the embedding carries no information about whether S2 was present or cloudy. Measured on synthetic mixtures (checks/sigreg_gap_result.md): a 50/50 two-stratum gap along one coordinate scores 1.05 under pooled SIGReg against 1.07 for a true Gaussian at K = 128, so pooled SIGReg cannot see it; stratified SIGReg does, but its sensitivity decays about 1/K. Pre-registered variants: K = 64, and an explicit stratum-mean penalty

Lμ = Σm ‖ (1/Nm) Σn: mn=m zn,v ‖2.

What it does not do: it does not align strata with each other (two strata can both be N(0, I) and be related by a rotation). Alignment is the job of Linv on paired views; the diagnostic is cross-stratum kNN retrieval of the same scene plus a linear probe for m and for the cloud fraction c that should fall to chance.

Total objective

L = (1 − λ) Linv + λ SIGRegstrat + λμ Lμ, λ = 0.05 (sweep {0.02, 0.05, 0.1} at the 5M model), λμ = 0 in the main arm, ablated over {0, λ, 10λ}; Tμ = Σm wm Nm ||meanm z||² / K, which has null expectation 1 and gradient 2wm meanm z / K.

Optimiser: AdamW with betas (0.9, 0.95), weight decay 0.05 (official code: LeJEPA 0.05/0.03/1e-5, LeVJEPA 0.04), drop-path 0 (both official recipes; our earlier 0.1 had no backing, so it is swept, not default), gradient clipping at 3.0 (our addition), bf16 autocast with fp32 master weights and the SIGReg characteristic function computed in fp32, no GradScaler. Learning rate 5e-4 at global batch 1024, linear warmup over 1500 steps from 0.01×lr, then a warmup-stable-decay schedule: the stable run checkpoints at 0.8 of each token budget and a child job decays linearly to lr/1000 over the remaining 20%, so one run yields five or more cooled checkpoints without replaying data. Neither official recipe uses WSD (MINIMAL: cosine to an absolute 1e-3; LeVJEPA: warmup then flat), so the WSD-versus-cosine gap is measured in P2 on ViT-S/2B before the grid. Also a departure, stated as such: LeJEPA reports a small ViT gain from SWA on the encoder producing μ (Table 4); we use no SWA or EMA anywhere.

What identifiability predicts (Q2)

Theorem (arXiv:2605.26379, fact): with stationary additive-noise latent transitions, the same observation function for both views, encoder output dimension equal to the latent dimension, and alignment plus Gaussian regularisation at the optimum, the encoder recovers the latents up to an orthogonal map. Prediction for two independently trained clean JEPAs: hB = Q hA, Q ∈ O(K). Test: orthogonal Procrustes from the SVD of HATHB on ncal ∈ {500, 1k, 5k, 20k} image embeddings; report ‖HB − HAQ‖2 / ‖HB‖2 against a general linear map and CCA. Hypothesis, not theorem: S1 and S2 are different observation functions of the scene, which the theorem does not cover.

Synthetic strata are a stated limitation

Both corpora are city-centred and cloud-filtered at collection, so the partly cloudy and S1-only cases the method is for barely exist in them. The paper must say which strata were synthesised and evaluate on real cloudy scenes from the benchmarks (Cloud-S2, Flood-S1, Sen1Floods11), not only on synthetic drops.
