These are the five recent independent review reports that informed the design:

**Read critically.** They contain proposals, differing upstream recipe interpretations,
toy measurements and estimates, not a verified EO study. Original reports are retained
for provenance; [the corrections register](../SOURCES.md) and [current formulation](../FORMULATION.md)
override them. Absolute paths and attachment links inside a report refer to the review
workspace and are not repository commands. Reported scripts/results have not become
the repository's tested training implementation merely by copying the reports here.

No source approval, split acceptance, cluster run or publication claim is implied.
